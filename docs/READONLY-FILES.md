# 只读文件：项目别名与本机绝对路径

文件接口只有 `files.list`、`files.stat`、`files.read`、`files.search`；不执行 shell，不写入、删除或修改目标文件，也不提升操作系统权限。返回内容可能发送给配置中受信任的 Slack 用户和 bot，请先确认这些接收者。

## 默认：项目别名

保持现有命令兼容，例如 `files.list` 的 `params`：

```json
{"root":"demo","path":"src","limit":20}
```

`root` 是本机配置中的项目别名，`path` 是该项目下的相对路径。提供 `root` 时仍按项目边界验证，不能把绝对路径或 `..` 放入 `path` 来逃出目录。

## 可选：绝对路径，不需要项目别名

`filePolicy.allowAbsolutePaths` 默认 **false**。在桌面应用中先停止连接器，在设置向导勾选“允许通过绝对路径读取系统文件”，保存时阅读并确认本机风险对话框，然后重新启动。导入配置只是预览；首次保存启用值仍需本机确认。CLI 用户可停止连接器后编辑自己的本地配置再启动：

```json
"filePolicy": { "allowAbsolutePaths": true }
```

这不是 Slack 命令参数，远端不能开启它。启用后，省略 `root` 并提供本机原生绝对路径。例如 `files.list` 的 `params`：

```json
{"path":"/Volumes/Code/My/Skills","limit":20}
```

完整命令仍须使用严格的开始/结束标记、唯一 `id`、正确 `target` 和可信 Slack 来源；以上仅是 `params` 示例，不是自然语言命令。Windows 原生路径在 JSON 中需要转义反斜线，例如 `{"path":"C:\\Work\\Skills"}`。不展开 `~` 或环境变量。

只有此开关为 true 时才允许 `projects: {}`。桌面中同时清空当前项目的别名与目录会移除该项目，保留其他已配置项目；仅清空一项会被拒绝。删除项目会影响默认会话可管理范围；`session.create` 仍需要配置好的项目别名。`sessionPolicy.allowAllSharedSessions` 是独立设置，不会因此开启。

## 安全边界与错误

- 启用意味着可信 Slack 接收者可请求读取此操作系统账户可读的任意普通文件，并非只读代码目录。只读也可能泄露数据。
- 敏感名称、常见凭据内容仍被拒绝，例如 `.env`、私钥、认证/状态文件。检测是尽力防护，**不能识别所有秘密，也不是完整 DLP**；不要因为有扫描就开放不可信接收者。
- 符号链接、目录 junction、硬链接文件、设备和其他特殊文件不支持；Windows UNC、设备命名空间、驱动器相对路径、ADS 等也不支持。不自动解析这些路径以绕过防护。即使目标正常，路径中的链接也可能导致拒绝。
- macOS 隐私保护、Windows ACL 和其他系统权限照常生效。请求入口本身权限不足返回 `ACCESS_DENIED`；遍历子目录时遇到不可访问项会跳过。搜索结果提供 `skippedFiles`，目录列表不会列出所有被跳过项。不要把无结果当成磁盘没有文件。
- 开关关闭时省略 `root` 返回 `ABSOLUTE_PATHS_DISABLED`；未知别名为 `ROOT_UNKNOWN`；受限路径为 `PATH_FORBIDDEN`；敏感正文为 `SENSITIVE_CONTENT`。文件变化可返回 `FILE_CHANGED`，不要盲目重试整棵磁盘扫描。
- 文件树不应被不可信本地进程同时改写；检查不能替代操作系统沙箱，也不保证消除所有跨平台文件系统竞态。

## 有界结果

| 操作 | 默认 / 上限 |
|---|---|
| list | 默认 100 条，最多 200 条 |
| read | 默认 16 KiB，单次最多 64 KiB；只读有效 UTF-8 普通文件，整个文件最多 1 MiB |
| search | 区分大小写的字面文本；默认 20 条，最多 100 条；默认深度 3，最多 8 |

遍历另有数量和累计字节预算。检查 `truncated`，不要声称输出完整；读取续页使用返回的字节 `nextOffset`，不要自行按字符计算。Slack 输出还受消息大小限制。使用 `help` 的单命令详情查看当前参数和错误类别。

本功能有本地合成文件树与 mock 回归测试；这些示例不代表已经读取或验证过你的实际路径。真实磁盘权限、原生平台路径及 Slack 端到端行为仍需在目标电脑验收。
